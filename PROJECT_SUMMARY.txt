================================================================================
                         SUPPORT & TROUBLESHOOTING
================================================================================

COMMON ISSUES:

1. Database Connection Failed
   - Ensure PostgreSQL is running
   - Check credentials in application.properties
   - Verify database secureapp_db exists
   - Run: psql -U postgres -h localhost -d secureapp_db

2. Session Tables Missing
   - Ensure SPRING_SESSION and SPRING_SESSION_ATTRIBUTES tables exist
   - Run init-database.sql to create them
   - Check spring.session.store-type=jdbc in application.properties

3. Port 8080 Already in Use
   - Change server.port in application.properties
   - Or kill existing process on port 8080

4. Maven Build Errors
   - Clear cache: mvn clean -U install
   - Update dependencies: mvn dependency:update-snapshots
   - Check Java version: java -version (should be 21)

5. Session Not Persisting
   - Verify SPRING_SESSION tables exist in database
   - Check spring.session.store-type=jdbc in application.properties
   - Ensure spring.session.jdbc.initialize-schema=never (tables created by init-database.sql)

For detailed documentation, see: README.md
